# DOO/IT – Kontroll- und Übergangsmodul

## Zweck
DOO/IT ist das Kontrollmodul des Systems.  
Es steuert Übergänge, aktiviert Durchlasspunkte und ermöglicht temporäre oder stabile Zustände.

## Struktur
- Modulname: DOO/IT  
- Typ: Control & Transition  
- Zustand: dynamisch  
- Kontrolle: aktivierbar  
- Übergang: stabil oder tmp  

## Funktionen
- Aktiviert DOOR-Module  
- Erzeugt Übergänge, wo keine vorhanden sind  
- Unterstützt API-Durchlass  
- Kann Mapping-Übergänge auslösen  
- Arbeitet unabhängig oder gekoppelt mit anderen Modulen

## Dateien
- ID.html – Modulidentität  
- index.html – Interaktive Testoberfläche
